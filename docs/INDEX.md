# INDEX — everything in this repository

> A complete map: the claim, the evidence, the code, the objections, and the limits.

---

## 1. The claim

> **“Every ledger header examined on Pi Mainnet reports `totalCoins` = 100,000,000,000 π, and the
> chain shows no issuance operation and no increment of the issuance counter — consistent with the
> documented protocol rule that removed native issuance before Pi’s genesis.”**

Not claimed: circulating supply, allocation, unlock schedules, price. Full statement:
`docs/SCOPE.md`.

## 4. Examples (all read-only, GET only, zero dependencies)

| File | What it does |
|---|---|
| `examples/lib.mjs` | Shared helpers: HTTP client with timeouts and 429 backoff, exact π/stroops arithmetic, validation, bounded-concurrency map, ledger sampler |
| `examples/xdr.mjs` | A strict XDR reader for the `LedgerHeader` structure |
| `examples/chain.mjs` | SHA-256 binding of the raw bytes: `sha256(header)` = the ledger hash, and adjacent headers chained |
| `examples/xdr-header.mjs` | Decodes the raw header bytes and cross-checks them against the API’s JSON |
| `examples/hash-chain.mjs` | Verifies a contiguous run of headers against the SHA-256 hash chain |
| `examples/supply-check.mjs` | Sweeps the observable range asserting `total_coins` = the cap; also shows `fee_pool` growing |
| `examples/op-check.mjs` | Tabulates the operation types the network actually runs, looking for issuance |
| `examples/self-test.mjs` | The test suite: offline unit tests + live assertions |
| `examples/check-links.mjs` | Verifies every relative link resolves from the file that contains it |
| `examples/run-all.mjs` | Runs everything, one verdict |
| `examples/regenerate-snapshots.mjs` | Regenerates the recorded evidence below |
